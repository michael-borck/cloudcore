# CloudCore - Quick Start for Lecturers

## 1 Minute Summary

**CloudCore** = Fake company website with AI employees for student assignments

**Students can:**
- Read company policies, org charts, budgets, logs
- Interview 16 AI employees via chatbot
- Gather requirements / perform audits / analyse systems

**You control:**
- What content they see
- When it unlocks
- Which employees they can interview

## Common Scenarios

**"I want students to do a security audit"**
→ Phase 1: Policies, org chart, compliance docs
→ Phase 2: Add incident reports, logs, CISO interview

**"I want students to gather requirements"**
→ Phase 1: All documentation
→ Phase 2: Add chatbot interviews

**"I want them to analyse a breach"**
→ Phase 1: Hide breach reports
→ Phase 2: Reveal breach + incident response docs
