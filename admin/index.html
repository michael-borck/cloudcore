Getting Started with Prose.io

1 Click "Open in Prose.io" above
2 Authorize with GitHub (first time only)
3 Navigate to the content folder:
  • docs/scenarios/ - Learning scenarios
  • docs/articles/ - Security incidents
  • docs/interviews/ - Character interviews
  • docs/policies/ - Company policies
  • blog/posts/ - Blog posts
4 Create new files or edit existing ones
5 Save with a descriptive commit message
